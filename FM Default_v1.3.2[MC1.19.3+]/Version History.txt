Ver. 1.2 - 12/22/2021
======================
The first public release for Minecraft 1.18

	Blocks
	======
	+Printed piglin banner pattern item texture.
	+3D models for copper ore, all deepslate ores and crimson/warped trapdoors.
	*New models for pre-existing Overworld ores to account for the official texture changes and to fix Z-fighting issues with other block models.
	*Small color palette change to soul fire.
	*Crying obsidian texture randomly rotates 180°, the same as normal obsidian.
	*Crimson and warped nylium and the target block randomly rotate in 90°-intervals about the Y-axis, identical to the grass block.

	Items
	=====
	+3D item models for crimson/warped signs, soul torch, soul lantern, candles and glow item frame.
	*Updated 3D item models for crimson, warped and polished blackstone buttons and lightning rod.
	*Axolotl and powdered snow buckets match the pre-established shape.
	*Changed crimson and warped doors to match pre-existing doors.
	*Waxed copper blocks have a honey trim, in item form only.

	GUI
	===
	*Updated smithing table UI.

	Particles
	=========
	*Small color palette change to soul fire flame.
	*Slimes use the slime block texture for their landing particles, instead of the slime ball sprite.

	Language File Changes
	=====================
	*"Block/Bucket of X" -> "X Block/Bucket" (ex: Block of Copper -> Copper Block)

	Optfine Only
	============
	-Removed all overlay textures.
	>> "These may return in a seperate pack, as having so many connected textures fundamentally changes the way players build. They enable builders to pack in more detail with less creative effort."
	>> "Plus, adding connecting textures for almost everything in Vanilla Minecraft alone is an insurmountable task."
	>> "Terraria inspired me to implement overlay textures in the first place. But come to think of it now, connected textures in that game fit better because the worlds are 2D, as opposed to 3D."
	*Reworked biome-dependent colormaps for water, skies and fog since numerical biome IDs were changed.
